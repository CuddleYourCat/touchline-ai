# touchline-ai

Live, explainable match intelligence for football fans, built on .NET 10 and Azure AI.

A seeded simulator plays a synthetic, football-realistic match. Every event streams through Azure Event Hubs, and only key moments wake a squad of AI agents. The agents explain why a moment happened, write live commentary, answer fans' questions with cited events, and produce a full-time recap in the fan's language.

> All clubs, players and match data are fictional and generated by the simulator.

Built for **Inside the Game: Developer Hackathon** (October 2026).

## Status

Kick-off: solution skeleton with Aspire, OpenTelemetry defaults and CI, plus the Azure environment (Container Apps, Foundry, Key Vault, monitoring) deployed from Bicep. See [DECISIONS.md](DECISIONS.md) for the architecture decisions.

## Run it locally

Requires the .NET 10 SDK and Docker.

```bash
dotnet run --project src/Touchline.AppHost
```

The Aspire dashboard opens with the simulator and the Match Centre API. `GET /api/status` on the Match Centre confirms it is up.

## Deploy to Azure

The infrastructure is hand-written Bicep in `infra/main.bicep` (ADR-012), deployed into its own resource group (ADR-011). It needs the Azure CLI, PowerShell 7 and a signed-in `az login`.

```bash
pwsh ./infra/deploy.ps1 -Action whatif
pwsh ./infra/deploy.ps1 -Action deploy
```

`whatif` previews the changes. `deploy` creates the resource group if needed, applies the template and prints the endpoints. `teardown` deletes everything and purges the soft-deleted Key Vault and Foundry account. No keys are used anywhere: services authenticate with a managed identity, and Foundry has local (key) authentication disabled.

## Architecture

| Layer | Azure service |
|---|---|
| Event stream | Azure Event Hubs |
| Event processing | Azure Functions |
| Match store | Azure Cosmos DB for NoSQL |
| Key-moment routing | Azure Service Bus |
| Retrieval | Azure AI Search (hybrid) |
| Models and agents | Microsoft Foundry |
| Hosting | Azure Container Apps + Container Registry |
| Identity and secrets | Managed identity + Key Vault |
| Observability | OpenTelemetry → Azure Monitor |
